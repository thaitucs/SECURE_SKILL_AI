# Skill_work

## SECURE_CHECK

Security audit, security score, frontend/backend file sorting, project restructuring, code
splitting and email/phone anti-spam for any app, web app or website, with any AI.

Kiểm tra bảo mật, chấm điểm bảo mật, phân loại file frontend/backend, sắp xếp lại dự án,
tách code và chống spam email/số điện thoại cho mọi app, web app, website, với mọi AI.

- Full guide (English + Tiếng Việt): [SECURE_CHECK/README.md](SECURE_CHECK/README.md)
- Entry point for AI / File chính cho AI: [SECURE_CHECK/SKILL.md](SECURE_CHECK/SKILL.md)

Quick start / Bắt đầu nhanh:

1. Copy the `SECURE_CHECK` folder to your AI tool (see the install table in the guide).
   Chép thư mục `SECURE_CHECK` vào công cụ AI của bạn (xem bảng cài đặt trong hướng dẫn).
2. Say / Nói với AI: **"Run SECURE_CHECK on this project"** / **"Chạy SECURE_CHECK cho dự án này"**.
3. Read / Đọc `secure-check-report/SECURE_CHECK_PLAN.txt`, then reply / rồi trả lời
   `APPROVE RECOMMENDED`, `APPROVE FIX-01 SPAM-02 ...` or / hoặc `SKIP`.
